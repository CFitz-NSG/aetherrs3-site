Website Privacy

This notice covers the public-facing website. Game accounts and gameplay are handled separately.

Visiting the site

This site provides game guides and community information. AetherRS3 uses no analytics or account sign-in on these pages.

GitHub Pages hosts this site. GitHub records visitor IP addresses for security. Some credited artwork loads from RuneScape Wiki and may be subject to its privacy policy.

GitHub Privacy Statement ↗

Downloads and community links

GitHub serves the launcher, and Oracle serves the Java installer. Community and vote links take you to third-party websites. The music suggestion tool prepares a draft in your browser for you to share.

Personal quest journal

Your quest marks stay in this browser. The website does not send them to a server or link them to a game account. To remove a mark, set that quest to Not started. Clearing site data removes all marks.

Questions

For website privacy questions, contact the AetherRS3 team through our community Discord.
